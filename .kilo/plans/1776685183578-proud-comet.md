# Plan: Ajouter Approbation Admin pour Impression Convocation

## Objectif
Modifier le système pour que les vérificateurs ne puissent imprimer une convocation qu'après approbation de l'administrateur désigné pour la signature.

## Nouvelle Architecture des Rôles

### Rôles Existants (inchangés)
- **Vérificateur** : Génère des convocations (droits maintenus)
- **Chrono** : Génère des convocations + accès étendu aux champs chrono (droits maintenus)  
- **Administrateur** : Peut approuver les convocations qui lui sont adressées (nouveau rôle)
- **Administrateur Technique** : Gestion complète utilisateurs/entreprises/opérateurs (droits maintenus)
- **Super Administrateur** : Droits maximum (droits maintenus)

### Nouvelles Relations et Workflow
1. **Création** : Vérificateur génère convocation → Statut = "EN_ATTENTE_APPROBATION"
2. **Approbation** : Administrateur désigné reçoit notification → Approuve/Rejette
3. **Impression** : Vérificateur peut télécharger/imprimer seulement si "APPROUVEE"

### États de Convocation
- `EN_ATTENTE_APPROBATION` : Générée, attente approbation admin
- `APPROUVEE` : Approuvée par admin, imprimable
- `REJETEE` : Rejetée par admin, non imprimable
- `IMPRIMEE` : Marquée comme imprimée (optionnel)

## Modifications Requises

### Base de Données
- Ajouter colonne `statut_approbation` à table `history` (ENUM: EN_ATTENTE_APPROBATION, APPROUVEE, REJETEE)
- Migration SQL pour ajouter la colonne avec valeur par défaut

### Backend (app.py)
- **Endpoint `/api/generate`** : Modifier pour définir statut = "EN_ATTENTE_APPROBATION"
- **Nouveau endpoint `/api/approve/<id>`** : POST (admin seulement) → statut = "APPROUVEE"
- **Nouveau endpoint `/api/reject/<id>`** : POST (admin seulement) → statut = "REJETEE" 
- **Endpoint `/api/history`** : Filtrer par rôle - admins voient convocations en attente d'approbation
- **Endpoint `/api/download/<filename>`** : Vérifier statut = "APPROUVEE" avant téléchargement
- **Endpoint `/api/history/<id>`** : PUT - admins peuvent modifier statut

### Frontend (React)
- **History.js** : 
  - Afficher colonne "Statut Approbation"
  - Boutons "Approuver/Rejeter" pour admins sur convocations en attente
  - Désactiver lien de téléchargement si non approuvé
- **Form.js** : Afficher message "Convocation créée, en attente d'approbation"
- **API calls** : Nouveaux appels pour approve/reject

### Scripts
- **convocation_mysql.py** : Pas de changement (génération inchangée)
- **db_config.py** : Pas de changement majeur

### Sécurité
- Vérifier que seul l'admin désigné (`signature_admin`) peut approuver sa convocation
- Logs d'approbation pour audit

### Tests
- Tester workflow complet : génération → approbation → téléchargement
- Tester permissions : vérificateur ne peut pas approuver, admin ne peut approuver que ses convocations
